# Troika Environmental — website package

This package recreates the supplied one-page PDF as a responsive web page.

## Files

- `index.html` — the publishable web page.
- `styles.css` — responsive layout and typography.
- `assets/background.webp` — optimized background image.
- `assets/background.jpg` — JPEG fallback.
- `assets/logo.png` — transparent-background logo extracted from the PDF.
- `assets/favicon.png` — browser favicon.
- `assets/social-preview.jpg` — complete artwork for link/social previews.
- `fonts/FreestyleScript-Regular.ttf` — embedded title font extracted from the PDF.
- `fonts/Calibri.ttf` — embedded email font extracted from the PDF.

## Publishing

Upload the contents of this folder to the root/public directory of your web host. The page does not require JavaScript, a build system, or a server-side framework.

The email address is configured as a `mailto:` link:
`info@troikaenvironmental.com.au`

## Source

The page content and visual treatment are based on the supplied PDF, which contains the wording “Trading strategies for Australian carbon market participants” and the contact address shown above.
